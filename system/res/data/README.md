# Data Directory

Contains input datasets for SemEval-2024 Task 1. Each subdirectory corresponds to a track:

- `a/` — Track A (Supervised)
- `b/` — Track B (Unsupervised)
- `c/` — Track C (Cross-lingual)
- `d/` — Track D
- `trans/` — English translations for non-English languages
- `paraphrase/` — Paraphrase datasets for PI training (optional)

See [`../README.md`](../README.md) for download instructions and full directory structure.
