# Data Directory

Contains input datasets for SemEval-2024 Task 1. Each subdirectory corresponds to a track:

- `a/` — [Track A](https://github.com/semantic-textual-relatedness/Semantic_Relatedness_SemEval2024/tree/main/Track%20A)
- `b/` — [Track B](https://github.com/semantic-textual-relatedness/Semantic_Relatedness_SemEval2024/tree/main/Track%20B)
- `c/` — [Track C](https://github.com/semantic-textual-relatedness/Semantic_Relatedness_SemEval2024/tree/main/Track%20C)

Download data from the [official competition page](https://codalab.lisn.upsaclay.fr/competitions/16799).
